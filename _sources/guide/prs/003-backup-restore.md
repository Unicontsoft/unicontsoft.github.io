# **Възстановяване**

> Възстановяването на база данни на **Dreem Personal** е възможно единствено, ако предварително е бил [направен архив](002-db-backup.md).  
> Строго препоръчваме създаване на регулярни архиви, съхранявани и на друго устройство.  

Възстановяване от архив е достъпно от форма **Установяване на самоличност**.  
Избира се бутонът с трите точки в края на поле **Профил**.  

![](903-backup-restore1.png){ class=align-center }

Това отваря помощника за поддръжка на системни бази данни.  

> На всяка от стъпките с бутон [**Напред**] се преминава към следващ етап на възстановяването.  
Процесът може да бъде прекъснат по всяко време с бутон [**Отказ**].  

![](903-backup-restore2.png){ class=align-center }

Избира се действие **Възстановяване на база данни от архив**.  

![](903-backup-restore3.png){ class=align-center }

Потвърждава се избор на профил **Dreem20_Personal**.  

![](903-backup-restore4.png){ class=align-center }

По подразбиране в поле **Архив на база данни** системата предлага  пътя до предварително направения архив (*C:\Program Files\Dreem Personal2.0\Backup\Dreem20_Personal_2026_09_24.7zip*). Друг архив на базата може да бъде избран чрез бутона с трите точки в края на полето.    

![](903-backup-restore5.png){ class=align-center }

Системата извежда съобщение с прогрес при разпакетирането на архив.  

![](903-backup-restore6.png){ class=align-center }

Отваря се форма с информация за име на базата данни и дата на архива.  

![](903-backup-restore7.png){ class=align-center }

Системата извежда прогрес за възстановяване на данни.  

> Времето за възстановяване зависи от големината на базата и параметрите на устройството, с което се работи.  

![](903-backup-restore8.png){ class=align-center }

След приклюване на процеса по възстановяване системата извежда съобщение с резултат.  
Бутон **ОК** връща отново към форма **Установяване на самоличност**.  

![](903-backup-restore9.png){ class=align-center }
