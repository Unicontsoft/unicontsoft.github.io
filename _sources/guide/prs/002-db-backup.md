# **Архивиране**

Архивирането на базата данни на **Dreem Personal** е най-добрата практика за сигурно съхраняване на данни.   

> Строго препоръчваме създаване на регулярни архиви, съхранявани и на друго устройство.  

Архивирането на базата данни е достъпно от форма **Установяване на самоличност**.  
Тя може да бъде отворена от:  

- Меню **Файл » Нова регистрация**  в системата
- При стартиране на системата (когато няма настройки за автоматично влизане)  

Избира се бутонът с трите точки в края на поле **Профил**.  

![](902-db-backup1.png){ class=align-center }

Това отваря помощника за поддръжка на системни бази данни.  

> На всяка от стъпките с бутон [**Напред**] се преминава към следващ етап на архивирането.  
Процесът може да бъде прекъснат по всяко време с бутон [**Отказ**].  

![](902-db-backup2.png){ class=align-center }

Избира се действие **Архивиране на база данни**.  

![](902-db-backup3.png){ class=align-center }

Потвърждава се избор на профил **Dreem20_Personal**.   

![](902-db-backup4.png){ class=align-center }

По подразбиране в поле **Път до архив** системата предлага *C:\Program Files\Dreem Personal2.0\Backup\Dreem20_Personal_2026_09_24.7zip*. Папката за архивиране на базата може да бъде променена чрез бутона с трите точки в края на полето.   
Името на файла съдържа датата на архивиране, като също може да бъде редактирано.  

![](902-db-backup5.png){ class=align-center }

Системата извежда прогрес за архивиране на данни.  

> Времето за архивиране зависи от големината на базата и параметрите на устройството, с което се работи.  

![](902-db-backup6.png){ class=align-center }

След приклюване на процеса по архивиране системата извежда съобщение с резултат.  
Бутон **ОК** връща отново към форма **Установяване на самоличност**.  

![](902-db-backup7.png){ class=align-center }
